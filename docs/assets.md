# Asset provenance

- `src/assets/hku-campus-map.png`: the original campus map embedded as `word/media/image2.png` in the user's supplied PRD. The original image is preserved; interactive SVG geometry is maintained separately in `src/data.ts`. Only the room IDs and operational data are fictional; the map itself is not a claim about current campus facilities.
- `src/assets/hku-crest.png`: an existing reproduction of the HKU coat of arms from `Covers/hkulogo.png` in https://github.com/monaen/HKU-Thesis-Template (retrieved 17 November 2026). It is used unchanged for this educational, noncommercial prototype. The repository states CC BY-NC-ND 4.0; the university's trademark rights remain with the university. This is a third-party reproduction, not a directly verified official brand asset. Verify the official permitted logo/wordmark source before distribution or production use. The adjacent university name is rendered as text, not represented as an exact official typeset wordmark.
- HKU Student Portal screenshots supplied by the user informed spacing, palette, icon style and header hierarchy. Portal HTML/CSS was not retrieved: its host was blocked by the environment's network policy. No login ticket was used or stored.
- Interface icons: Lucide React (ISC). Fonts use local system sans-serif fallbacks and a serif fallback for the university name, with no external font service.

No screenshot personal names, portal news, student records or login credentials are included.
